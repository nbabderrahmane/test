# Étude — mini-jeux addictifs et viraux (24 novembre 2026)

Recherche web 2024-2026. Les notes d'effort et de potentiel sont un jugement, pas une mesure.

## Genres classés (effort / addictif / viral)
1. Déduction de mot ou de code du jour — S / haute / très haute
2. Logique de grille à règles simples — M / haute / haute
3. Regroupement par catégories cachées, contenu local — S / haute / haute
4. Tri de couleurs ou de pièces, niveaux progressifs — S / haute / moyenne  ← **lot 1**
5. Merge — M / très haute / moyenne
6. Arcade à un doigt, score à battre — S / haute / moyenne
7. Quiz chronométré à série, contenu local — S / haute / haute
8. Mémoire / séquence — S / moyenne / moyenne
9. Puzzle physique léger — M / haute / moyenne
10. Idle / clicker — M / haute / moyenne (lassitude, dérive « gagner de l'argent »)

## Six ressorts de rétention
1. Défi quotidien unique, identique pour tous (NYT Games : ~11,2 Md de parties en 2025).
2. Série visible, avec protection (LinkedIn annonce 84 % de retour le lendemain — chiffre auto-déclaré).
3. Partage du résultat sans spoiler, en un tap.
4. Difficulté progressive, « presque réussi ».
5. Sessions de 1 à 3 minutes, reprise instantanée.
6. Classement léger entre proches plutôt que mondial.

Repère : rétention J1 médiane ~22 %, ~40 % pour le top 10 % (GameAnalytics 2026).

## Enseignements super-apps
- WeChat : 500 M d'utilisateurs mensuels de mini-jeux ; le casual sert d'accroche, l'effort porte sur la rétention.
- Telegram : la viralité par récompense financière retient mal (5-20 % après les airdrops).
- Afrique francophone, apps télécom : aucune donnée sourcée trouvée — à tester par prototype.
